Tulki — lokal serverni internetga ochish

Bepul, ochiq tunnel servisi. Musanna hisobi orqali kiring.

Boshqaruv paneliga kirish

Tulki nima?

  • Lokal serverlaringizni internetga ochish uchun bepul, ochiq tunnel xizmati.
  • TCP protokollarini qo'llab-quvvatlaydi: HTTP, SSH va boshqalar.

O'rnatish / yangilash (Linux, macOS)

$ curl -fsSL https://tulki.uz/install.sh | sudo bash

O'rnatish / yangilash (Windows)

PowerShell'da:

PS> iwr -useb https://tulki.uz/install.ps1 | iex

Avtorizatsiya

Avval me.musanna.uz/api-keys sahifasidan API kalit yarating, so'ngra:

$ jprq auth <your-auth-token>

HTTP tunnel ochish

3000 ni o'zingiz xohlagan port bilan almashtiring

$ jprq http 3000

TCP tunnel ochish

Har qanday TCP server uchun (masalan, SSH)

$ jprq tcp 22

O'z subdomeningiz bilan

"custom" o'rniga xohlagan subdomeningizni yozing

$ jprq http 3000 -s custom

Static fayllarni serve qilish

"." o'rniga xohlagan papkangizni ko'rsating

$ jprq serve .

Debug rejimi

Debug dashboard URL'i konsolda chiqadi

$ jprq http 3000 --debug

O'z domeningiz orqali (CNAME)

example.com o'rniga o'z domeningizni yozing.
Domen CNAME yozuvi sizning jprq subdomeningizga ishora qilishi kerak.

$ jprq http 3000 --cname example.com
